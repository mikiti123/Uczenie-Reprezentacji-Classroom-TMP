# miniproject - Autoenkodery + Autoenkodery generatywne
<hr>
    
Celem dzisiejszych zajęć jest poznanie podstawowego modelu Autoenkodera oraz modelu bardziej rozbudowanego zwanego <b>VAE</b>. Na podstawie przykładowego zbioru danych zrozumiemy dokładne działanie tych dwóch modeli. W podstawowym modelu Autoenkodera zostanie zobrazowane jego działanie oraz podane zastosowanie w uczeniu częściowo nadzorowanym. 

Repozytorium zawiera pliki:
1. Podstawowy_Autoenkoder.ipynb - plik ten wyjaśnia działanie podstawowego Autoenkodera oraz znajdują się w nim <b>2</b> zadania
2. functions_Podstawowy_Autoenkoder.py - pomocniczne funkcje do pliku " Podstawowy_Autoenkoder.ipynb"
3. requirements.txt - zestaw potrzebnych bibliotek do uruchomienia kodu
4. images - folder ze zdjęciami potrzebnymi do notebooków



### Konfiguracja środowiska
<hr>

W trakcie tych ćwiczeń będziemy korzystać z notatników Jupyter Notebook. Aby przygotować środowisko, należy zainstalować niezbędne biblioteki z pliku requirements.txt. Zaleca się przygotowanie wcześniej wirtualnego środowiska:
Stwórz środowisko z użyciem `conda`:
```bash
$ conda create -n .venv python=3.13
```

zainstaluj niezbędne bilioteki:
```bash
$ source .venv/bin/activate
$ pip install -r requirements.txt
```
